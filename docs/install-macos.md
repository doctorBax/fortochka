# Установка Fortochka на macOS

Путь: скачал → перетащил в Applications → один раз разблокировал → пользуется.
Терминал не нужен, но для тех, кому так удобнее, вариант с командой тоже приведён.

## Что нужно

- macOS 11 (Big Sur) или новее. Сборка universal — работает и на Intel, и на
  Apple Silicon (M1/M2/M3/M4), скачивается одна на всех
- Около 500 МБ места
- Установленный Telegram на телефоне для входа в аккаунт

## Установка

1. Скачайте `fortochka-mac-0.2.0.dmg` со страницы
   [Releases](https://github.com/doctorBax/fortochka/releases/latest) — файл около 150 МБ.
2. Откройте скачанный DMG двойным кликом.
3. Перетащите иконку Fortochka на папку Applications, которая рядом в окне.
4. Дождитесь окончания копирования, закройте окно и извлеките диск
   (правый клик по диску на рабочем столе → «Извлечь»).
5. Запустите Fortochka из папки «Программы» (Applications).

## Первый запуск: предупреждение Gatekeeper

Приложение не подписано сертификатом Apple Developer (он платный, $99/год), поэтому
macOS при первом запуске покажет предупреждение вида: «Fortochka» не открыть —
не удалось проверить наличие вредоносного ПО. Это ожидаемо: приложение не повреждено
и не удалено, просто macOS не знает издателя. Предупреждение появляется один раз.

### macOS 14–15 и новее (Sonoma, Sequoia)

1. В окне с предупреждением нажмите **Готово** (Done).
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите до блока «Безопасность» — там будет запись про заблокированную Fortochka.
   Нажмите **«Открыть в любом случае»** (Open Anyway).
4. В появившемся диалоге нажмите **Открыть**.

Готово — больше предупреждений не будет. На macOS 15 (Sequoia) кнопка правого клика
«Открыть» больше не работает, этот путь — единственный без Терминала.

### macOS 13 и старше (Ventura, Monterey, Big Sur)

Правый клик по Fortochka в Applications → **Открыть** → в диалоге ещё раз
**Открыть**. После этого приложение запускается обычным двойным кликом.

### Через Терминал (то же самое, одной командой)

```
xattr -cr /Applications/Fortochka.app
```

Команда снимает карантинную пометку. Выполнять один раз.

## Если пишет «приложение повреждено и не может быть открыто»

Это та же карантинная пометка, просто на некоторых версиях macOS сообщение звучит
так. Лечение — команда из блока выше, после неё приложение открывается.

## После запуска

- Войдите в аккаунт: по номеру телефона (код придёт в Telegram на телефоне) или по
  QR-коду — в мобильном Telegram: Настройки → Устройства → Привязать устройство.
- Если при входе сайт попросит капчу — она разрешена и загрузится сама.
- Количество непрочитанных показывается бейджем на иконке в доке.
- Закрытие окна прячет приложение — оно остаётся в доке и меню-баре. Полный выход:
  Cmd+Q или иконка в меню-баре → Выход.

## Обновления

Автообновления на macOS нет: приложение сообщит о новой версии (иконка в меню-баре →
«Проверить обновления»), новый DMG скачивается вручную с
[Releases](https://github.com/doctorBax/fortochka/releases/latest) и ставится поверх
старой версии. Сессия и настройки сохраняются — профиль лежит отдельно, в
`~/Library/Application Support/fortochka/`.

## Удаление

Перетащите Fortochka из Applications в корзину. Данные профиля лежат в
`~/Library/Application Support/fortochka/` — удалите папку, если хотите убрать всё
(сессия, кэш, настройки).
